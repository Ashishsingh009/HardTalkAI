## Full description (~4000-character max)

```
HardTalkAI is a flight simulator for difficult career conversations.

Pick a manager or leadership drill — asking for a raise, giving critical feedback, saying no to extra work, pushing back on an impossible date, advocating in calibration, and more. Talk to an AI counterpart who reacts to your tone. Coach Heather scores each reply on clarity, empathy, and assertiveness, then you retry.

This is practice → score → retry, not an open-ended chatbot.

WHAT YOU GET
• A catalog of career drills (the raise is Free practice; other drills unlock with Pro)
• Live scores and specific tips after each turn
• A counterpart who warms up or gets guarded based on how you show up
• A three-turn round on Android, then a recap: how scores moved and one thing to try next

WHO IT’S FOR
ICs and managers who want a private place to rehearse the talk before the real 1:1.

WHAT THIS BUILD IS
A Shipaton prototype. On Android, the raise drill is free; other catalog scenarios unlock with a monthly HardTalk Pro subscription (RevenueCat / Google Play). There is no account. Coaching scores are computed by our server. If the operator has configured OpenAI, the counterpart’s lines are generated by that model; otherwise you still get a deterministic in-character reply.

WHAT IT IS NOT
Not a therapist, not HR, not legal advice, and not a live coach. Do not put secrets, customer data, or real personnel files into the chat.

Privacy: practice messages go to the coaching API so we can score them and reply. We do not sell personal information. Full policy: linked from the app and from the Play listing.

Questions: hello@hardtalk.ai (or aashish2k2@gmail.com if that inbox is not live yet).
```

## Data safety (Play form cheat-sheet)

Collects:

- **Messages** — practice replies + round history, sent to the HardTalkAI API to provide the coaching feature. Optionally forwarded to OpenAI when `OPENAI_API_KEY` is set on the server. Not sold. Not used for ads. Not shared with other users.

Does not collect (this build): location, name/email in-app, photos, contacts, app-activity analytics.

Purchase data for Android Pro is handled by Google Play and RevenueCat (subscription status / app user id). We do not collect card numbers in the app.

Encryption in transit: **yes on production HTTPS**. Debug/emulator builds may use cleartext HTTP to a local FastAPI — do not ship that as the store default.

Account deletion: no accounts. Chat is not stored in a database in this prototype.

## Screenshot shot list (capture on Android)

Play wants **phone** screenshots (JPEG/PNG). Use a **9:16** emulator or device (Pixel 6 / 8 class). Do not upload web browser chrome. Capture **after** the splash.

Aim for **4 screenshots** in this order. Show real coaching UI, not empty states.

### 1. Catalog with Free badge (and 2–3 scenario cards)

- Screen: scenario list (`HardTalk AI` / Career coaching · Coach Heather).
- Must show the **Free practice** chip on **Ask your manager for a raise**.
- Frame **2–3 cards** in the shot: raise (Dana), **Give a teammate critical feedback** (Sam), and if it fits **Say no to extra work** (Priya). Crop so titles and the free badge are readable — do not show a huge empty gradient.
- Optional lede in frame: “Pick a drill, get scored, retry”.
- Hide or crop the debug `API: http://10.0.2.2:3001` line if it is in the shot (status bar crop or a later release that tucks debug URL). If it must stay, that is fine for internal testing; swap for production screenshots before production.

### 2. In-round scores

- Start the **raise** drill (Dana).
- Send a real practice line (strong numbered ask, or a hedged one if you want a guarded mood).
- Capture the thread with **Turn N coaching**, overall score, **Clarity / Empathy / Assertiveness** bars, tips (“Try this”), and Dana’s reply.
- Coach Heather’s panel (goals + mood) in the same frame is a plus if it still reads at phone width.

### 3. End-of-round recap

- Finish **three scored turns** on Android.
- Capture **Round complete**: “How scores moved” (`N → M`), counterpart mood, and **one thing to try next**.
- Include **Try this scenario again** / **Choose another scenario** so the loop is obvious.

### 4. Extra cards / second drill (if Play allows more than 3)

- Catalog scrolled so **2–3 leadership cards** show (impossible date, calibration, skip-level), **or**
- Mid-round **critical feedback** (Sam) with scores — empathy vs assertiveness demo.

**Do not capture:** splash spinner, error “is FastAPI running”, empty composer before the first send, iOS, or the web app.
