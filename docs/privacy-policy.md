# Privacy policy — HardTalkAI

**Last updated:** 28 October 2026

This is a short, honest policy for a **prototype**. It is not legal advice and it does not claim GDPR/CCPA certification, a Data Protection Officer, or a production-grade retention program. If something here is wrong for how you run the app, fix the app or fix this page before you ship.

HardTalkAI (“the app”) is a **career coaching practice tool** (Coach Heather / leadership lane). You pick a workplace scenario, send practice replies to an AI counterpart, and get scores on clarity, empathy, and assertiveness. On Android you can optionally **call the counterpart** (a short interruptible 1:1). Coach Heather scores the transcript after you hang up — she is not on the call.

## What we collect (when you practice)

The app does **not** create accounts. There is no sign-in, profile, or email capture in this build.

When you run a **typed** drill, the client sends to our coaching API (`POST /api/chat`):

- the **scenario id** you picked
- the **text you typed** (your practice reply)
- the **conversation history** for that round (your earlier replies and the counterpart’s lines)

We use that payload only to score the turn and generate the next counterpart line. Coaching scores and tips are computed on our server. The scenario list (`GET /api/scenarios`) is fetched so the catalog can render.

### Optional Android counterpart call

If you tap **Call** on Android and grant the microphone, the app:

1. Asks our API (`POST /api/voice/session`) for a short-lived OpenAI Realtime client secret (about 120 seconds; never your main API key)
2. Streams **microphone audio** over WebRTC **directly to OpenAI** so the counterpart can speak and be interrupted
3. Sends the **transcript** to our API (`POST /api/voice/complete`) so we can score up to three user utterances with the same local rubric as typed practice

Audio for a live call is processed by OpenAI. We do not keep a recording on our servers. The call is capped at three user speech segments or about 90 seconds. Typed practice does **not** use the microphone.

This prototype **does not write practice chats to a database**. The request is handled in memory. Ordinary web-server logs may still record IP address, time, and the URL path. Error logs may include a stack trace; they are not a chat archive.

### First-party funnel counts

The FastAPI host keeps a short in-memory log of **funnel steps** so operators can see catalog → drill → recap → Send PayPal invoice conversion (`GET /analytics` and `GET /api/analytics/funnel`). Each row is an event name, optional scenario id, optional channel (`typed` / `voice`), and a random session token from `X-HardTalk-Session`. **Practice replies, emails, and invoice amounts are not stored in that log.** Counts vanish when the process restarts. There is no Mixpanel, Amplitude, or other third-party analytics SDK.

### Optional OpenAI

If the operator sets `OPENAI_API_KEY` on the server:

- Typed counterpart replies are generated by OpenAI (default model `gpt-4o-mini` unless `OPENAI_MODEL` is set). The **scenario prompt, history, and your latest message** are sent to OpenAI.
- Live calls use OpenAI Realtime (default model `gpt-realtime` unless `OPENAI_REALTIME_MODEL` is set). **Audio and the scenario instructions** go to OpenAI.

If no key is set, or the operator has not configured `HARDTALK_VOICE_SECRET`, the server uses a built-in deterministic reply, **Call** is hidden (`voice: false` on `/api/health`), and the server **does not** mint a Realtime session.

Coaching scores/tips are **not** sent to OpenAI; they stay on our server.

OpenAI’s handling of that data is governed by [OpenAI’s privacy policy](https://openai.com/policies/privacy-policy). We do not control their retention.

### Optional PayPal sandbox invoice

After the **Chase an overdue invoice** drill, Android can show a review screen. If you tap **Send PayPal invoice**, the client posts the reviewed terms (amount, currency, due date, recipient name/email, line-item description) to our API (`POST /api/invoice/send`). That API creates and sends a **PayPal sandbox** invoice when `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET` are set. If they are not set, the server returns a clearly labeled **mock** invoice and does not call PayPal. Nothing is sent unless you tap the button. Term extraction (`POST /api/invoice/extract`) sends the round transcript to our server (and to OpenAI if a key is configured) so the form can be pre-filled.

## What we do not collect / do not do

- We **do not sell** personal information.
- We **do not** run ads, attribution SDKs, or third-party analytics packages. First-party funnel counts (event name, scenario id, session token) may sit in memory on the coaching API until restart.
- We **do not** ask for your name, email, phone, location, contacts, or photos. Android **Call** asks for the **microphone** only when you start a counterpart call.
- Android may take a **Play** payment to unlock HardTalk Pro (the paid catalog). That purchase is processed by Google Play and RevenueCat. We do not create an account for you. The raise and overdue-invoice drills stay free. Web and the public Static Space demo are not paywalled.
- Practice messages are **not** posted publicly and are **not** shown to other users.
- Children: this is a workplace-coaching prototype aimed at adults. Do not use it if you are under 13. We do not knowingly collect data from children.

Android’s `INTERNET` permission is used to reach the coaching API and, for a live call, OpenAI Realtime. `RECORD_AUDIO` is used only for the optional counterpart call. Debug builds may talk to a machine on your network over HTTP; a store build should point at HTTPS.

## Retention and deletion

Because this prototype does not store chats in a database, there is usually **nothing to delete** on our side after the request finishes. If you believe a log or a hosted environment kept something of yours, email [hello@hardtalk.ai](mailto:hello@hardtalk.ai) or [aashish2k2@gmail.com](mailto:aashish2k2@gmail.com) and we will look.

If OpenAI was enabled for that session (typed reply or a live call), we cannot erase copies that may exist in their systems; contact them as well if needed.
